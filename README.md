# Nokia Ottawa Innovation Campus — 3D Representation

Interactive 3D presentation of the Electron Metal 48RU cabinet, prepared for Nokia
(Ottawa Innovation Campus).

## Contents

- `index.html` — self-contained single-page presentation. Open it directly in a
  browser, or serve the folder over HTTP.

## Local preview

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```
